*   [3. Otimizações de Performance](./coding-standards.md) — Padrões de código e regras de otimização de renderização/fontes para alta velocidade móvel.
*   [4. Otimização para Mecanismos de Busca](./seo.md) — Especificações de metadados, OpenGraph e dados estruturados JSON-LD LocalBusiness.
