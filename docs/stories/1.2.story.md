# Story 1.2: Estrutura do Header e Menu de Navegação Semântico

## Story
**As a** visitante do site,
**I want** visualizar um cabeçalho fixo com o logotipo e menu de links rápidos de navegação,
**so that** eu possa acessar qualquer seção do site de forma ágil e intuitiva.

## Acceptance Criteria
1. O cabeçalho deve usar a tag HTML5 `<header>` e ser fixado no topo da tela (`position: fixed`) com transparência fosca e desfoque de fundo (*backdrop-filter*).
2. O menu de navegação (`<nav>`) deve conter links ancorados (`#home`, `#sobre`, `#servicos`, `#roi`, `#contato`) que realizem rolagem suave (`scroll-behavior: smooth`).
3. Incluir um botão CTA no lado direito do menu destacando a cor Dourado Colheita com efeito de hover.
4. Versão Mobile: O menu deve se adaptar para um formato Hamburguer que desliza de forma fluida a partir do canto direito.

## Dev Notes
**Technical Context (From `docs/front-end-spec.md`)**:
- A implementação não utilizará frameworks, apenas Vanilla JS/CSS.
- **Hierarquia DOM**: A estrutura principal deve envolver uma `<header class="header">`, com um container interno (ex: `header-container` limitando largura), contendo a `.logo`, a `<nav class="nav-menu">`, e o `.nav-cta`.
- **Estilos do Header**: Cor de fundo `rgba(8, 28, 21, 0.8)` garante contraste para textos brancos. A borda inferior é de `rgba(255,255,255,0.05)`.
- **Efeitos de Transição**: Lembrar de reutilizar ou aplicar a ideia de `.transition-smooth` criada na Story 1.1 para suavizar as micro-interações do menu.

### Testing
- Validar se o header gruda perfeitamente no topo ao scrollar a página.
- Validar se clicar nos links realiza o scroll para a posição correta (necessário ter as seções placeholder `section#id` no HTML para teste, ou apenas verificar via inspeção).
- Validar o menu Hamburger mobile: o painel abre? Transiciona fluidamente? Pode ser fechado?
