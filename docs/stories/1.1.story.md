## Story
**As a** desenvolvedor,
**I want** estruturar o arquivo de estilos globais (`index.css`) com variáveis CSS baseadas no sistema de design (cores, espaçamento, fontes),
**so that** o restante das seções mantenha consistência estética rígida.

## Acceptance Criteria
1. O arquivo `index.css` deve conter as variáveis CSS oficiais para as cores: Verde Obsidian, Verde Floresta, Verde Eucalyptus, Dourado Colheita e Alabaster.
2. Importar as fontes *Outfit* (títulos) e *Inter* (texto) do Google Fonts.
3. Definir estilos resets consistentes para margens, preenchimentos e box-sizing em todos os navegadores.

## Dev Notes
**Technical Context (From `docs/front-end-spec.md`)**:
- **Design System Tokens**:
  - `var(--color-obsidian-green)`: `hsl(162, 53%, 7%)`
  - `var(--color-forest-green)`: `hsl(154, 42%, 18%)`
  - `var(--color-eucalyptus-green)`: `hsl(154, 38%, 34%)`
  - `var(--color-mint-light)`: `hsl(152, 24%, 60%)`
  - `var(--color-golden-harvest)`: `hsl(43, 100%, 51%)`
  - `var(--color-alabaster)`: `hsl(0, 0%, 98%)`
  - `var(--color-snow-white)`: `hsl(0, 0%, 100%)`
  - `var(--color-charcoal-dark)`: `hsl(160, 20%, 15%)`
  - `var(--color-gray-muted)`: `hsl(0, 0%, 65%)`
- **Gradientes**: `--gradient-obsidian`, `--gradient-forest`, `--gradient-harvest`
- **Tipografia**: `var(--font-primary)` = 'Outfit', `var(--font-secondary)` = 'Inter'
- **Escala de Fontes**: Responsiva via clamp() conforme `docs/front-end-spec.md`
- **Glassmorphism**: Classe `.glass-card` com backdrop-filter, border, box-shadow e border-radius.
- **Espaçamento**: Grid layout e bordas suaves padrão (8px, 16px, 24px)
- **Micro-animações**: Classe `.transition-smooth`, `.card-hover:hover`, `@keyframes whatsapp-pulse`.
- **Arquitetura**: O projeto é uma Single Page Application estática e leve com CSS customizado (sem frameworks CSS como Tailwind).
